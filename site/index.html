THE WORKFLOW

From source to review

Each step remains visible so a visitor can inspect how the result was produced.

01

Ingest

Paste an invoice or select a UTF-8 text file. The separate FastAPI service also reads PDFs and can use OCR for scanned pages.

02

Extract

Parse labeled fields and simple line items into JSON. The public browser demo uses deterministic text rules.

03

Verify

Trace fields back to source lines and compare known values. Mismatches are marked for human review.

IN THE REPOSITORY

Python service

FastAPI accepts PDF and text uploads, uses PyMuPDF for embedded text, falls back to Tesseract OCR, and offers a server-side optional model path.

  • Upload limit: 5 MB / 10 PDF pages
  • Expected-field evaluation endpoint
  • Docker setup and parser tests
